# Documentation Index

This directory is organized by audience and lifecycle.

## Handover

Operational and plant-PC documents used for installation, daily operation,
backup/recovery, incident response, release packaging, and readiness signoff.

Start with [Production Handover Index](handover/production-handover-index.md).

## Developer

Documents for contributors and maintainers, including local setup, codebase
orientation, debugging, and safe change guidance.

Start with [Developer Guide](developer/developer-guide.md).

## Reference

Technical references for architecture, data model, environment variables, meter
configuration, PostgreSQL verification, and the OpenAPI contract.

## Archive

Historical, pilot-specific, demo-specific, transitional, or superseded material.
Archived documents are retained for traceability but are not the primary operating
instructions. Current procedures should be updated in `handover/`, `developer/`,
or `reference/`.
